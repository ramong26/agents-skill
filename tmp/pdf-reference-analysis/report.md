## 실제 관찰값

이 수치는 참조의 특성을 설명하는 관찰값이며 복제할 규격이 아니다. 특히 기존 대상 스킬의 최소 10.5pt 기준을 유지해야 하므로 참조의 작은 활자와 51pt 여백을 그대로 적용하지 않는다.

- 페이지: 8쪽, 594.96 × 841.92pt, A4 세로에 해당.
- 공통 콘텐츠: x=51.0~544.5pt, 폭 493.5pt. 좌우 여백 약 18mm.
- 2~8쪽 헤더: 7.5pt 회색, 글자 상단 y=43.81pt. 아래 구분선 y=62.25pt, 두께 0.75pt.
- 쪽번호: 우측 하단 `2 / 8` 형식, 7.5pt, 글자 하단 y=818.56pt. 표지는 생략.
- 추출 폰트: `AAAAAA+Pretendard-Regular`, `BAAAAA+Pretendard-Bold`, `CAAAAA+Pretendard-SemiBold`, `DAAAAA+Pretendard-Medium`. 앞부분은 PDF 서브셋 식별자.
- 표지: 제목 30pt Bold, 부제 13pt Regular.
- 본문: 대제목 13.5pt Bold, 소제목 10.5pt Bold, 설명 9.4pt Regular, 표 본문·헤더 8.8pt Regular/SemiBold, 주석 주로 8.4pt. 7쪽 도식은 6.62~8.18pt로 가장 작음.
- 색: 본문 #1A1A1A, 주석 #666666, 헤더·쪽번호 #777777. 표 헤더 #EEEEEE, 그룹 칸 #F6F6F6, 내부선 #BDBDBD, 상단선 #555555. RGB 추출값을 반올림한 코드.
- 표 구획선: 주로 두께 0.75pt의 얇은 사각형. 사진과 브랜드 컬러 없음.
- 4쪽 표 불릿의 동일 글꼴 글자 상단 간격: 15~15.75pt. 8.8pt 크기 대비 약 1.7배. 정확한 원본 문단 line-height나 baseline 설정은 미확인.
- 3쪽 표: 헤더 높이 21pt, 일반 1행 약 20.25pt, 셀 경계~글자 시작의 좌측 패딩 약 6.75pt. 상하 패딩 설정은 미확인.
- 3쪽 반복 표 열폭: 약 129 / 301.5 / 64.5pt, 비율 약 26 / 61 / 13%. 짧은 분류값은 중앙 정렬.
- 제목·본문 간격의 원본 스타일 설정은 미확인. 추출 위치의 예로 3쪽 대제목 글자 상단 y=74.51pt, 이어지는 설명 상단 y=106.12pt이며 상단 간 거리는 31.61pt이다. 이를 제목 하단 여백 값으로 해석하면 안 된다.
- 본문 하단: 2~3쪽 약 y=736~747pt, 4~8쪽 약 y=525~610pt. 내용 단위 페이지 분할이 우선되어 밀도 차이가 있음.

## 재사용할 형태와 조정할 값

- 재사용: 일관된 왼쪽 축, 문서명 헤더와 우측 쪽번호, 단색 위계, 반복 가능한 표 구조, 그룹 세로 병합, 짧은 ID 중앙 정렬, 표 하단 보조 주석.
- 재사용: 설명을 불릿·비교표·단계 카드로 전환하고, 화면·시스템·일정은 각 목적에 맞는 도식으로 표현한다.
- 재사용: 내용 단위로 페이지를 나누고 제목과 표를 함께 유지한다. 실제로 표 중간이나 소제목 직후의 페이지 분할은 관찰되지 않았다.
- 조정: 본문 11pt, 표·보조 텍스트 최소 10.5pt라는 기존 기준을 유지하며 위계는 크기와 굵기의 비율로 재현한다. 필요한 페이지를 늘려 작은 글씨로 압축하지 않는다.
- 조정: 여백·표 행높이·패딩은 확대된 활자에 맞추어 대상 스킬 기준으로 정한다. 51pt 여백과 20~21pt 행높이는 관찰값일 뿐 고정 복제하지 않는다.
- 조정: 도식 라벨과 일정 주차 텍스트도 최소 크기를 지키고, 메모 칸은 실제 입력이나 필기를 위한 높이를 확보한다.

## 품질과 한계

8페이지 전체 렌더에서 겹침·잘림·깨진 한글은 발견하지 않았다. 장점은 안정된 정렬, 일관된 Pretendard, 표를 통한 실무 비교, 흑백 출력 친화성이다. 한계는 작은 표 활자, 7쪽 극소 글자, 페이지별 밀도 차이, 좁은 메모 공간이다.

미확인: 원본 작성 도구·스타일 설정, 인쇄 실물, 선택 칸의 PDF 폼 기능, 접근성 태그 구조. 정확한 baseline·상하 패딩·제목 여백 설정은 추출 좌표만으로 확정하지 않았다.
