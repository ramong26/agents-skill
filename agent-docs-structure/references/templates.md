# 템플릿

프로젝트의 작성 언어와 문체는 기존 문서를 따른다. 아래는 뼈대일 뿐이며 항목 이름은 바꿔도 된다.

## AGENTS.md

```markdown
# <프로젝트 이름> 에이전트 지침

## 1. 읽기 순서

아래 순서대로 읽는다. 조건부가 아니다. 사용자에게 무엇을 할지 묻기 전에 여기까지 확인한다.

1. `docs/tasks/README.md` — 작업 목록 표에서 `진행 중`인 작업을 찾는다.
2. 해당 작업 폴더의 `README.md` — 진행도와 `이어서 할 일` 줄을 읽는다.
3. 그 스텝 파일 — 체크되지 않은 첫 항목이 다음에 할 일이다.
4. 구조나 범위를 바꾸는 작업이면 `docs/structure/ARCHITECTURE.md`와 `ROADMAP.md`를 읽는다.

## 2. 폴더별 책임

| 경로                             | 담는 것                 | 갱신 시점               |
| -------------------------------- | ----------------------- | ----------------------- |
| `README.md`                      | 제품 목표, 원칙, 범위   | 범위가 바뀔 때          |
| `docs/structure/ARCHITECTURE.md` | 바뀌지 않는 구조 결정   | 구조 결정이 바뀔 때만   |
| `docs/structure/ROADMAP.md`      | 단계 구분과 완료 조건   | 단계가 끝날 때          |
| `docs/tasks/README.md`           | 전체 작업 목록과 상태   | 작업 상태가 바뀔 때     |
| `docs/tasks/NN-<작업>/`          | 그 작업의 스텝과 진행도 | 체크 하나를 끝낼 때마다 |

## 3. 변경 규칙

- 새 문서는 위 표와 폴더 구조 양쪽에 등재한다. 등재할 자리가 없으면 만들지 않는다.
- 문서 하나가 200줄을 넘으면 더 쓰지 않는다. 분리 기준과 예상 줄 수를 제안해 승인을 받은 뒤 분리한다.
- 작업 하나 = 폴더 하나 = 브랜치 하나 = PR 하나.
- 작업 폴더는 끝나도 지우지 않는다.
- 작업 시작 절차: 폴더와 README 생성 → 스텝 파일 작성 → 사용자 검토 → 승인 후 구현.
- 직전 요청의 승인을 그 뒤에 만든 변경으로 확대 적용하지 않는다.

## 4. 작업 종료 전 확인

- [ ] 끝낸 체크 항목을 `- [x]`로 바꿨다
- [ ] 작업 폴더 README의 진행도 `(끝낸 수/전체 수)`와 `이어서 할 일` 줄을 갱신했다
- [ ] `docs/tasks/README.md` 표의 상태를 갱신했다
- [ ] 단계의 모든 작업이 끝났다면 `ROADMAP.md` 상태 줄을 갱신했다
- [ ] 충족하지 못한 완료 조건은 체크하지 않고 남은 내용을 보고했다
```

## docs/tasks/README.md

```markdown
# 작업 목록

| 번호 | 작업        | 상태          | 단계    |
| ---- | ----------- | ------------- | ------- |
| 01   | <작업 이름> | 완료          | Phase 1 |
| 02   | <작업 이름> | 진행 중 (3/9) | Phase 1 |
| 03   | <작업 이름> | 대기          | Phase 2 |

상태 값: `대기` / `진행 중 (끝낸 수/전체 수)` / `완료` / `보류`.

표는 처음부터 전부 채운다. 스텝 파일은 그 작업을 시작할 때 쓴다.
```

## docs/tasks/NN-<작업>/README.md

```markdown
# NN. <작업 이름>

## 목표

<이 작업이 끝나면 무엇이 가능해지는지 한두 문장>

## 범위

- 포함: <...>
- 제외: <...>

## 스텝

- [x] 01-<스텝 이름> — 완료 (4/4)
- [ ] 02-<스텝 이름> — 진행 중 (3/9)
- [ ] 03-<스텝 이름> — 대기 (0/5)

이어서 할 일: `02-<스텝 이름>.md`의 4번째 체크 항목

## 완료 조건

- <명령>을 실행하면 <출력>이 나온다
- <경로>에 <파일>이 생성된다
```
