# requirements-kit

AI는 **빠뜨린 것 찾기와 초안 만들기**를 맡는다. 의도를 확정하는 건 요청자다.
이 스킬의 목적은 확인받지 않은 내용으로 코드를 쓰는 것을 막는 것이다.

## 관문 두 개

1. **착수 관문** — `docs/requirements/<기능>/1pager.md`의 상태가 `✅ 확인됨`이 아니면 화면 코드를 쓰지 않는다.
   멈추고 사용자에게 알린 뒤, 확인 요청 메시지(`references/04` ①)를 제안한다.
2. **변경 관문** — 확인된 1-pager와 흐름·화면 구성·범위·완료 기준이 달라지는 코드는 쓰기 전에 멈춘다.
   무엇이 달라지는지 알리고, 변경 확인 메시지(`references/04` ③)와 결정·변경 로그에 넣을 행을 제안한다.

사용자가 "확인 없이 진행"이라고 명시하면 진행하되, 결정·변경 로그에 `요청자 확인: 없음(진행 사유)` 행을 남긴다.

## 지킬 것

- 상태를 `✅ 확인됨`으로 **직접 바꾸지 않는다.** 사용자가 요청자 확인을 받았다고 말할 때만 바꾸고, 누가 언제 확인했는지 같이 적는다.
- 모르는 건 채우지 않는다. `[확인 필요: 무엇을 누구에게]`로 남긴다.
- 요청자가 한 말과 추측을 구분한다. 추측에는 `(추측)`을 붙인다.
- 흐름은 요청자가 준 **실제 예시 건 숫자**로 채운다. 없으면 열린 질문에 넣는다.
- 피드백에 흐름 이야기가 없으면 동의로 보지 않는다. 흐름만 따로 묻는 메시지(`references/04` ②)를 제안한다.
- 화면 대안은 코드로 만들지 않고 목업으로 2개까지 보여 준다.
- 결정·변경 로그의 `정한 사람`과 `요청자 확인`을 섞지 않는다.
- 계산·변환이 있으면 완료 기준에 "머지 전 요청자 실제 자료와 결과 일치"를 넣는다.

## 작업별로 할 일

요청에 맞는 것만 한다. 각 작업의 세부 지시는 `references/03-AI-프롬프트.md`의 같은 번호를 따른다.

| 요청 | 할 일 | 쓰는 템플릿 | 저장 위치 |
|---|---|---|---|
| 새 프로젝트 시작 | 착수 체크리스트 초안 | `references/00-프로젝트-착수.md` | `docs/requirements/00-프로젝트-착수.md` |
| 킥오프 질문 | ① 질문 뽑기 (10개 이내, 쉬운 말) | `references/01-킥오프-질문.md` | 저장 안 함, 채팅으로 |
| 메모·대화 정리 | ② 1-pager 초안 | `references/02-1pager.md` | `docs/requirements/<기능>/1pager.md` |
| 흐름 정리 | ③ 흐름 표 + Mermaid + 예외 | 1-pager 4·5번 | 같은 1-pager |
| 목업 | ④ 로우파이 와이어프레임 | — | 사용자에게 보여 주기 |
| 리뷰 | ⑤ 롤백 위험 찾기 | — | 채팅으로, 열린 질문 추가 제안 |
| 완료 기준 | ⑥ 체크리스트 | 1-pager 8번 | 같은 1-pager |
| 화면·흐름 변경 | ⑦ 변경 관문 점검 | `references/04` ③ | 1-pager 9번에 행 추가 |
| 확인 메시지 | 상황에 맞는 메시지 | `references/04-확인-메시지.md` | 채팅으로 |

작업 크기:
- S(문구·필드 하나): `01`의 ★ 질문 3개 + `04` ⑥ 한 줄 확인. 1-pager 없음.
- M(새 화면·화면 구성 변경): 1-pager.
- L(새 흐름·새 프로젝트): 1-pager + 목업 + 중간 시연(`04` ④). 새 프로젝트면 `00` 먼저.
- 애매하면 한 단계 큰 쪽.

## 답변 끝에

만든 초안마다 "요청자에게 확인받을 것"을 3개 이내로 짚고, 보낼 메시지를 제안한다.

## 프로젝트에 적용

1. 이 폴더를 프로젝트의 `.claude/skills/requirements-kit`에 복사한다. (전역 설치는 이 저장소 README 참고)
2. 프로젝트의 `AGENTS.md`(또는 `CLAUDE.md`)에 한 줄 추가. 스킬은 호출될 때만 읽히므로, 관문은 항상 읽히는 파일에 둔다:
   ```markdown
   - 새 화면이나 화면 흐름·구성을 바꾸는 코드를 쓰기 전에 `docs/requirements/<기능>/1pager.md` 상태를 확인한다. `✅ 확인됨`이 아니거나 확인된 내용과 달라지면 멈추고 알린다. 1-pager가 없으면 먼저 만들지 묻는다. (requirements-kit 스킬)
   ```
3. 원본은 `ramong26/agents-skill`의 이 폴더 하나다. 양식을 고치면 원본을 고치고 다시 복사한다.
